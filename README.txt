# 🌌 COSMORA – Explore Beyond the Stars

**An Interactive Space Exploration Platform**

> Journey through planets, discover distant galaxies, explore space missions, and uncover the mysteries of our universe.

COSMORA is a visually immersive and interactive frontend web project designed to make space exploration engaging, educational, and accessible to everyone.

Built with a futuristic cosmic design, smooth animations, interactive elements, and responsive layouts, COSMORA offers users a digital journey through the wonders of space.

---

## 🚀 Project Overview

COSMORA brings the universe closer through an interactive digital experience.

Users can explore the eight planets of our solar system, discover beautiful astronomical objects, learn about historic space missions, and uncover fascinating facts about the universe.

The project focuses on combining creative UI/UX design with practical frontend development concepts.

## ⚙️ Getting Started

Follow these steps to run COSMORA locally.

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd COSMORA
```

**3. Open the project**

Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.

**4. Explore the universe!**

Navigate through the website and explore its interactive features.

## 🌍 API Integration

COSMORA can use NASA's Open APIs to access real astronomical content.

- NASA API Portal: https://api.nasa.gov/
- NASA Astronomy Picture of the Day (APOD): https://apod.nasa.gov/apod/astropix.html

An API key may be required for certain endpoints. Follow NASA's usage guidelines and keep API credentials out of public repositories.
